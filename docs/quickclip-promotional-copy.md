# QuickClip 产品介绍

## 一句话定位

**QuickClip 是 DaVinci Resolve 的效率工具链**——从项目搭建到最终交付，把重复劳动交给工具，把创意留给画面。

---

## 核心能力

### 项目管理，一次配好

项目初始化、媒体池结构、素材打包、备份导出——把达芬奇项目本该有的规范流程，做成开箱即用的自动化。不再手动创建文件夹，不再纠结命名规则，从第一个素材到最终交付，井然有序。

### AI 工作流，文本即剪辑

本地语音引擎将音频转为带词级时间戳的文本，选中段落一键生成时间线。口播视频、采访、课程录制——删掉多余的废话，剪辑就完成了。说话人自动分离，支持热词优化，数据全程不出本地。

### 实用工具集

字幕智能换行、搜索替换、插入时间线，跟随视频变速自动重对齐。粘贴审阅链接同步时间戳评论，对照修改不漏一条。时间线检查自动发现黑边、夹帧、空白片段，一键标记问题位置。

### 音效库，拖拽即用

分类浏览、全文搜索、波形预览，拖拽到时间线自动导入项目媒体池。未使用的音效自动清理，已用的自动归档——音效管理不再混乱。

### 命令行 & AI Agent 支持

全套 Python CLI 工具，覆盖项目管理、转录、字幕编辑和导出。Agent Skill 接口预备中，未来支持 Claude Code 等 AI 助手直接调用，为批量操作和脚本编排铺路。

---

## 适合谁用

- **自媒体创作者**：口播、Vlog、教学内容，转录即剪辑，大幅缩短出片时间
- **专业剪辑师**：项目规范管理、音效库、时间线检查，日常工作的可靠伙伴
- **小型工作室**：统一团队项目结构，标准化交付流程，按人数灵活定价

---

## 技术亮点

- 基于 faster-whisper 的本地语音引擎，支持字级时间戳和说话人分离
- 与 DaVinci Resolve 深度集成，直接操作媒体池、时间线和导出模块
- macOS 原生体验，支持暗色/亮色主题自动切换
- 桌面端（Tauri） + 命令行（Python CLI）双模式
