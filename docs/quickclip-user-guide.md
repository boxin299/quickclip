# QuickClip 使用教程

## 一、欢迎使用 QuickClip

### 1.1 产品简介

QuickClip 是一款面向 DaVinci Resolve 的桌面辅助剪辑工具。它通过本地 AI 语音引擎将音频转为带时间戳的文本，让你像编辑 Word 文档一样剪辑视频——选中想要的文本段落，一键生成时间线。

核心能力：

- **AI 转录**：基于 faster-whisper 的本地语音引擎，支持字级时间戳和说话人分离，数据全程不出本地
- **文本驱动剪辑**：在转录文本上选中片段，一键生成或追加到达芬奇时间线
- **字幕处理**：智能换行、搜索替换、变速跟踪对齐
- **音效库**：分类浏览、波形预览，拖拽到时间线自动导入媒体池
- **审阅同步**：粘贴审阅链接，拉取时间戳评论对照修改
- **素材打包**：扫描时间线引用的素材，一键打包导出

### 1.2 安装与启动

**环境要求：**

- macOS 操作系统
- DaVinci Resolve 已安装并运行
- Python 3.10+（后端自动管理）
- Node.js 18+（桌面端自动管理）

**启动方式：**

在项目根目录双击 `start-app.command`，或在终端中运行：

```bash
./start-app.command
```

启动后，桌面应用窗口会自动打开。首次使用需要登录账号并激活设备。

### 1.3 界面概览

QuickClip 的界面分为三个区域：

- **左侧边栏**：功能导航，按分组排列。顶部可在「主工作区」和「音效库」之间切换
- **中央主区域**：当前选中功能的操作面板
- **底部状态栏**：显示达芬奇连接状态、当前时间线名称和分辨率

功能导航分为四个分组：

| 分组 | 功能 |
|------|------|
| 项目管理 | 项目初始化、文件层级管理、素材打包、导出与备份 |
| AI 工作流 | 音频转录、文本剪辑 |
| 实用工具 | 同步审阅、字幕处理、时间线检查、剪贴导入 |
| 系统 | 偏好设置 |

## 二、快速入门

以下流程带你完成第一个 QuickClip 项目，约需 5 分钟。

### 步骤 1：登录并激活

启动应用后，在登录页输入邮箱和密码登录。首次使用需要输入激活码激活设备。

> 激活码可在 [quickclip.top](https://quickclip.top) 获取。一个激活码可注册多台设备，支持 7 天免费试用。

### 步骤 2：创建项目

登录后进入「项目初始化」页面。选择一个本地素材目录，QuickClip 会自动创建达芬奇项目并搭建标准化的媒体池结构。

点击「选择本地素材目录」选择文件夹，输入项目名称，然后点击「创建项目」。

### 步骤 3：导入视频

项目创建完成后，将视频文件放入项目的素材目录中。QuickClip 会自动检测新文件。

你也可以使用「剪贴导入」功能——直接从 Finder 复制图片或视频文件，QuickClip 会自动将其导入到达芬奇当前项目的媒体池中。

### 步骤 4：转录音频

切换到「音频转录」页面，选择视频作为转录源，点击「开始转录」。QuickClip 使用本地语音引擎将音频转为带词级时间戳的文本。

转录完成后，你会看到按说话人分组的文本段落，每个词都附有精确的时间戳。

### 步骤 5：文本剪辑

切换到「文本剪辑」页面，浏览转录文本。用鼠标框选想要的文本段落（或点击选中整句），选中的段落会高亮显示。

点击「生成新时间线」或「追加到当前时间线」，QuickClip 会将选中的文本对应的时间段自动剪辑到达芬奇时间线上。

### 步骤 6：字幕处理（可选）

在「字幕处理」页面，你可以对生成的字幕进行精细编辑——智能换行、搜索替换特定文字、调整字幕跟随视频变速对齐。

### 步骤 7：导出

切换到「导出与备份」页面，配置导出命名模板和渲染预置，点击导出即可在达芬奇中开始渲染。

## 三、项目管理

### 3.1 创建与配置项目

进入「项目初始化」页面后：

1. 点击「选择本地素材目录」，选择硬盘上的文件夹作为项目根目录
2. QuickClip 会根据文件夹名称自动建议项目名称，你也可以手动修改
3. 点击「创建项目」，QuickClip 会：
   - 在达芬奇中创建同名项目
   - 搭建标准化媒体池结构（视频、音频、图片、序列等文件夹）
   - 建立本地目录与达芬奇媒体池的映射关系

如果项目已经存在，QuickClip 会识别并加载已有项目信息。

### 3.2 文件夹结构管理

「文件层级管理」页面展示媒体池中的文件夹层级结构。你可以查看深层嵌套的素材，将其展平到指定层级以便管理。

页面还支持三种视图：

- **本地文件结构**：硬盘上的实际文件夹目录
- **达芬奇媒体池结构**：导入到达芬奇内部的文件夹（箱）
- **导入映射规则**：配置本地目录到媒体池的对应关系

在映射规则页面，你可以设置哪些本地文件夹对应达芬奇媒体池中的哪些箱，实现自动分类导入。

### 3.3 项目上下文与切换

QuickClip 会自动检测达芬奇中当前打开的项目。在达芬奇中切换项目后，QuickClip 会自动同步项目上下文，包括导入的视频列表和转录数据。

底部状态栏会实时显示连接状态和当前时间线信息。如果达芬奇意外断开，状态栏会提示「离线」，点击即可重新连接。

## 四、视频导入

### 4.1 拖拽 / 选择导入

在项目初始化完成后，将视频文件放入项目素材目录，QuickClip 会自动检测新文件并显示在已导入列表中。

在「音频转录」页面，你可以从已导入视频列表中选择转录源，也可以直接拖拽视频文件到页面上进行转录。

### 4.2 剪贴板自动导入

「剪贴导入」是一个后台服务，运行后会自动监听系统剪贴板：

- 从 Finder 复制图片（JPG、PNG 等）或视频文件
- QuickClip 自动检测并导入到达芬奇当前项目的媒体池
- 支持配置本地文件夹和达芬奇目标文件夹的映射规则
- 文件以时间戳格式命名，避免重名冲突

在「剪贴导入」页面可以开启 / 关闭服务，查看最近的导入记录和状态。

## 五、AI 转录

QuickClip 内置基于 faster-whisper 的本地语音识别引擎，数据全程在本地处理，不上传任何服务器。

### 5.1 从时间线转录

如果达芬奇当前时间线中有视频片段，你可以选择「从时间线」模式，QuickClip 会提取时间线上的音频进行转录。这种方式最适合已经完成粗剪、需要精细化调整的场景。

### 5.2 从已导入视频转录

选择「已导入」模式，从已导入到项目中的视频列表中选择一个文件进行转录。

### 5.3 拖拽文件转录

直接将视频或音频文件拖拽到转录页面，QuickClip 会接受该文件并开始转录，无需事先导入到项目中。

### 5.4 说话人分离与热词优化

转录引擎支持：

- **说话人分离**：自动识别不同说话人并将文本按说话人分组展示
- **说话人命名**：在文本剪辑页面，你可以为每个说话人指定名称（如"主持人"、"嘉宾"），方便识别和管理
- **热词优化**：在设置中可以添加领域专用词汇，提高转录准确率

## 六、文本驱动剪辑

文本驱动剪辑是 QuickClip 的核心功能——在转录文本上直接选择想要的片段，一键生成时间线。

### 6.1 转录文本浏览与筛选

进入「文本剪辑」页面后，你会看到按说话人分组的转录文本。每段文本显示：

- 说话人标签
- 文本内容（每个词附带时间戳）
- 时间范围（开始时间 - 结束时间）

你可以展开 / 折叠每个说话人的文本组，快速定位到需要的内容。

### 6.2 说话人管理与命名

转录时自动识别说话人，以编号显示（如「说话人 0」「说话人 1」）。你可以：

- 点击说话人标签重命名
- 添加新的自定义说话人
- 修改某段的说话人归属

命名后所有界面都会同步更新，方便识别。

### 6.3 选中 / 取消片段

在文本上操作：

- **框选文本**：按住鼠标拖拽，选中一段连续文本
- **点击整句**：点击句子任意位置，选中整句
- **取消选中**：再次点击已选中的句子可取消选中

选中的文本会高亮显示，页面底部会实时统计已选段落数量和总时长。

### 6.4 拆分与合并段落

- **拆分**：在句子中间点击拆分按钮，将一段文本分成两段
- **合并**：相邻的短段落会自动合并（间隔小于 0.5 秒），减少时间线碎片

### 6.5 一键生成时间线

选中满意的文本段落后，点击页面底部的操作按钮：

- **生成新时间线**：在达芬奇中创建一条新时间线，包含所有选中段落对应的视频片段
- **追加到当前时间线**：将选中的片段追加到达芬奇当前时间线的末尾

QuickClip 将根据文本的时间戳自动定位到视频中的对应位置，完成精确剪辑。

## 七、字幕编辑器

字幕编辑器用于对转录生成的字幕进行精细编辑和调整。

### 7.1 字幕编辑器概览

进入「字幕处理」页面，你会看到字幕列表。每条字幕显示：

- 序号
- 文本内容（可编辑）
- 开始时间和结束时间
- 时长

你可以直接编辑字幕文本，修改后的字幕可以导出或插入到达芬奇时间线。

### 7.2 智能换行

字幕编辑器支持智能换行功能：

- 将光标放在需要换行的位置，按 `Enter` 键
- QuickClip 会根据上下文自动判断最佳断行位置
- 断行后的字幕会自动调整时间戳

这个功能对于将长字幕拆分为多条短字幕特别实用。

### 7.3 搜索替换

搜索功能帮助你快速定位和修改特定文字：

- 输入关键词搜索，匹配的字幕会高亮显示
- 支持替换功能——将所有匹配的文字替换为新文字
- 搜索结果会显示匹配数量和位置

### 7.4 变速跟踪对齐

如果达芬奇时间线中有变速片段，字幕编辑器可以：

- 跟踪视频变速信息
- 自动重新对齐字幕时间戳
- 确保字幕与变速后的画面保持同步

## 八、字幕生成器

### 8.1 从音频生成字幕

「音频转录」页面在完成转录后，会自动将转录结果转化为字幕格式。你可以在转录完成后直接切换到字幕编辑器进行编辑。

转录项目会被保存，下次打开时可以加载已有的转录结果，无需重新转录。

### 8.2 样式配置

在「偏好设置」页面可以配置字幕的默认样式参数，包括输出格式和帧率设置。字幕编辑器中的帧率设置会影响时间戳的计算精度。

## 九、导出

### 9.1 导出命名模板

「导出与备份」页面提供灵活的命名模板系统。你可以用变量标签组合出需要的文件名格式：

| 变量 | 含义 |
|------|------|
| `%ProjectName%` | 项目名称 |
| `%TimelineName%` | 时间线名称 |
| `%DateTime%` | 当前日期时间 |
| 自定义文本 | 手动输入的任意文字 |
| 版本号 | 可编辑的版本号（如 V01） |

拖拽排列标签即可搭建命名模板，实时预览最终文件名效果。

### 9.2 预置方案管理

QuickClip 内置了达芬奇常见导出预置（H.264、H.265、ProRes 等），你可以：

- 选择需要的导出预置
- 添加自定义预置
- 删除不需要的预置

### 9.3 执行导出

配置好命名模板和预置方案后，点击导出按钮。QuickClip 会：

1. 根据模板生成导出文件名
2. 自动备份当前时间线
3. 将渲染任务添加到到达芬奇渲染队列

你可以在达芬奇的「交付」页面查看渲染进度。

## 十、音效库

音效库是一个独立的工作区，通过顶部标签页切换到「音效库」即可进入。

### 10.1 浏览与搜索音效

音效库以分类树的形式展示所有音效文件：

- 左侧显示音效分类目录树
- 点击分类查看该类别下的所有音效
- 支持全文搜索——输入关键词快速找到需要的音效

音效库会自动扫描配置的音效目录，发现新文件后自动加入索引。

### 10.2 波形预览

选中音效文件后，右侧会显示音频波形图：

- 可视化查看音频的起伏变化
- 点击播放按钮试听音效
- 支持暂停和重新播放

波形数据会被缓存，二次查看几乎即时加载。

### 10.3 拖拽到时间线

找到合适的音效后，直接拖拽音效文件到达芬奇时间线：

- 音效文件会自动导入到达芬奇项目媒体池
- 在时间线播放头位置插入音频片段
- 支持 Tauri 原生拖拽，拖拽体验流畅

### 10.4 音效分类管理

音效库支持：

- **收藏标记**：给常用音效添加收藏标记
- **标签管理**：为音效添加自定义标签，方便分类检索
- **使用统计**：标记已使用的音效，未使用的音效可以一键清理
- **自动归档**：已使用的音效自动归档到媒体池对应文件夹

## 十一、审阅同步

「同步审阅」功能帮助你整合审阅反馈，高效对照修改。

### 11.1 粘贴审阅链接

在「同步审阅」页面，粘贴达芬奇的审阅分享链接。QuickClip 会通过链接拉取审阅会话中的所有评论。

支持创建多个审阅项目，每个项目独立管理。

### 11.2 时间戳评论同步

拉取评论后，每条评论会显示：

- 评论者的头像和名称
- 评论内容
- 关联的时间戳（点击可跳转到时间线对应位置）
- 评论状态（已解决 / 未解决）

### 11.3 逐条对照修改

你可以逐条查看评论，对照时间线进行修改。每处理完一条评论，可以将其标记为「已完成」。进度条会显示整体处理进度，确保不遗漏任何反馈。

---

## 十二、素材打包

### 12.1 扫描时间线引用

「素材打包」页面会扫描达芬奇当前时间线中所有引用的素材，包括：

- 时间线上的视频和音频片段
- 合成片段（Fusion Clip）引用的素材
- 嵌套时间线引用的素材

页面以层级树的方式展示素材依赖关系，一目了然。

### 12.2 打包与导出素材

勾选需要打包的素材，选择目标目录，点击打包。QuickClip 会将选中的素材文件复制到目标目录，保持原始文件结构。

这个功能在需要将项目素材交接给其他人或备份归档时非常实用。

## 十四、常见问题

### QuickClip 无法连接达芬奇

1. 确保 DaVinci Resolve 已启动并打开了一个项目
2. 检查达芬奇偏好设置中是否启用了外部脚本控制（DaVinci Resolve → Preferences → General → External Scripting）
3. 点击底部状态栏的「离线」按钮尝试重新连接

### 转录结果显示「模拟模式」

这意味着本机尚未安装 faster-whisper 模型。检查后端是否正确配置了语音识别模型依赖。首次启动时后端会自动下载模型，可能需要一定时间。

### 音效库中找不到文件

确保在「偏好设置」中正确配置了音效库目录路径。音效库支持配置多个目录，配置后需要点击「重新扫描」来更新索引。

### 剪贴导入没有反应

1. 检查「剪贴导入」页面的服务开关是否已开启
2. 确认达芬奇已连接并有打开的项目
3. 检查文件夹映射配置是否正确

### 激活码提示无效或已用完

1. 确认激活码输入正确（注意大小写）
2. 在管理后台检查激活码状态
3. 如已用完，需要管理员生成新的激活码或增加使用次数
