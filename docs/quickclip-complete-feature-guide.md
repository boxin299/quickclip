# QuickClip 完整功能教学文档（按导航顺序）

## 1. 文档定位

本文是一份按 QuickClip 界面导航顺序编写的功能手册。阅读方式很简单：从左侧导航最上方的功能开始，一个功能一个功能往下看。每个功能都会独立说明：

- 每个功能适合解决什么问题。
- 使用前需要准备什么。
- 在界面中应该怎么操作。
- 操作完成后会产生什么结果。
- 这个功能和前后功能如何配套使用。
- 出现异常时应该先检查哪里。

如果你是第一次使用 QuickClip，建议先阅读「基础概念」，然后从「项目初始化」开始按顺序往下看。如果你已经熟悉软件，可以直接跳到对应功能章节查阅。

## 2. 软件整体能力

QuickClip 是面向 DaVinci Resolve 的本地辅助剪辑工具。它的核心思路是：把达芬奇里的素材、时间线、字幕、审阅意见、音效和导出流程，统一放到一个更适合批量处理的桌面工具中。

主要能力包括：

| 功能组 | 功能 | 用途 |
|---|---|---|
| 项目管理 | 项目初始化 | 绑定本地素材目录，创建或识别达芬奇项目 |
| 项目管理 | 文件层级管理 | 查看媒体池层级，展平深层文件夹，清理图片素材 |
| 项目管理 | 素材打包 | 扫描当前时间线引用素材，并复制到交付目录 |
| 项目管理 | 导出与备份 | 组合导出命名模板，调用达芬奇渲染和时间线备份 |
| AI 工作流 | 音频转录 | 从达芬奇时间线或本地文件生成带时间戳的文本 |
| AI 工作流 | 文本剪辑 | 在转录文本中选择内容，一键生成或追加时间线 |
| AI 工作流 | 字幕处理 | 编辑字幕、搜索替换、插入达芬奇、同步变速时间线 |
| 实用工具 | 同步审阅 | 拉取阅流评论，跳转时间线，将评论写入达芬奇标记 |
| 实用工具 | 时间线检查 | 检查夹帧、黑帧间隙、黑边风险，并定位或标记问题 |
| 实用工具 | 剪贴导入 | 监听剪贴板图片，自动保存并导入当前达芬奇媒体池 |
| 独立工作区 | 音效库 | 扫描音效库、搜索试听、打标签、收藏、拖入时间线 |
| 系统 | 偏好设置 | 管理运行依赖、模型、主题、更新、技能安装和第三方配置 |

## 3. 基础概念

### 3.1 DaVinci Resolve 连接状态

QuickClip 的大多数功能都依赖 DaVinci Resolve。软件底部状态栏会显示连接状态、当前项目和当前时间线。

状态含义：

| 状态 | 含义 | 处理方式 |
|---|---|---|
| 已连接 | QuickClip 能访问当前达芬奇项目 | 可以正常执行时间线、媒体池、导出相关功能 |
| 离线 | 没有连接到达芬奇或脚本接口不可用 | 先打开 DaVinci Resolve，并打开一个项目，再点击重连 |
| 后端运行中但未连接 | 本地服务正常，但达芬奇不可用 | 检查达芬奇是否启动、项目是否打开、外部脚本控制是否开启 |

建议在开始工作前先确认：

1. DaVinci Resolve 已打开。
2. 达芬奇中已经打开目标项目。
3. QuickClip 状态栏显示当前项目名称。
4. 当前时间线名称和分辨率能正常显示。

### 3.2 本地素材路径

本地素材路径是 QuickClip 的项目根目录。很多功能都会依赖它：

- 项目初始化会把它写入项目上下文。
- 剪贴导入会把复制来的图片保存到这个目录下的指定子文件夹。
- 文本剪辑跨项目使用时，会把源素材复制到当前项目目录。
- 导出与备份会根据它推导默认导出目录。
- 素材打包会用它判断素材相对路径和交付层级。

如果本地素材路径错误，常见表现包括：

- 导出目录不符合预期。
- 剪贴导入提示未检测到项目。
- 跨项目文本剪辑无法正确导入源素材。
- 素材打包预览层级不准确。

### 3.3 媒体池目录

媒体池目录指 DaVinci Resolve 项目中的 Bin 路径。QuickClip 会在多个功能中使用它：

- 项目初始化会创建标准媒体池结构。
- 文件夹映射会把本地目录和达芬奇媒体池目录对应起来。
- 剪贴导入会把图片导入到指定媒体池目录。
- 音效库会把使用过的音效归档到指定媒体池目录。
- 跨项目文本剪辑会把复制来的素材导入到指定媒体池目录。

### 3.4 转录项目

音频转录完成后会生成一个转录项目。转录项目包括：

- 原始来源信息，例如时间线音频或本地文件。
- 文本段落。
- 词级时间戳。
- 说话人信息。
- 字幕草稿。
- 与达芬奇项目的绑定关系。

转录项目可以在「音频转录」「文本剪辑」「字幕处理」三个页面之间复用。

绑定方式：

| 绑定方式 | 含义 | 适合场景 |
|---|---|---|
| 全局 | 所有达芬奇项目都显示该转录项目 | 公共素材、通用采访、跨项目复用 |
| 当前项目 | 跟随当前打开的达芬奇项目显示 | 当前工作只围绕一个项目推进 |
| 原始项目 | 只在创建该转录时的达芬奇项目中显示 | 防止不同客户或不同项目文稿混淆 |

### 3.5 选中片段与时间线生成

QuickClip 的文本剪辑使用「选中」来表示需要保留或追加的内容。被选中的内容会被转换成时间段，并发送给达芬奇。

支持两类选择：

- 整段选择：选中完整句子或完整段落。
- 词级选择：只选中一句中的部分词语。

生成时间线时，QuickClip 会把连续的选中词或段落合并为剪辑片段，减少碎片。

## 4. 安装与启动

### 4.1 启动方式

在项目根目录运行：

```bash
./start-app.command
```

也可以在 Finder 中双击 `start-app.command`。

启动脚本会自动进入 `frontend` 目录，并通过 Tauri 拉起前端和后端服务。

### 4.2 首次启动建议

首次启动后，建议按以下顺序检查：

1. 打开 DaVinci Resolve。
2. 打开一个达芬奇项目。
3. 启动 QuickClip。
4. 进入「偏好设置」查看运行环境。
5. 如果转录模型缺失，先安装模型。
6. 回到「项目初始化」绑定本地素材路径。

### 4.3 偏好设置中的运行环境

「偏好设置」会检查：

- 后端服务。
- Python。
- FFmpeg。
- faster-whisper。
- 说话人分离模型。

如果 faster-whisper 或说话人分离模型缺失，转录能力会受影响。可以在偏好设置中安装或删除模型。

## 6. 项目初始化

### 6.1 功能用途

「项目初始化」用于建立 QuickClip 与当前达芬奇项目、本地素材目录之间的关系。

它解决的问题是：

- 当前达芬奇项目对应哪个本地文件夹。
- 新项目是否需要自动创建。
- 本地目录和达芬奇媒体池结构是否统一。
- 后续导入、导出、打包和剪贴板导入应该使用哪个根路径。

### 6.2 使用前准备

请先确认：

1. DaVinci Resolve 已启动。
2. 已经打开目标项目，或准备创建新项目。
3. 本地已经准备好项目素材根目录。

### 6.3 创建新项目

操作步骤：

1. 进入「项目初始化」。
2. 点击「选择文件夹」。
3. 选择本地素材目录。
4. 软件会尝试根据文件夹名称自动填入项目名称。
5. 检查项目名称是否正确。
6. 点击「立即创建项目」。

完成后，QuickClip 会把该目录记录为当前项目路径，并尝试在达芬奇中创建或初始化对应项目。

### 6.4 绑定已有项目

如果达芬奇中已经打开一个项目，QuickClip 会显示当前项目名称，并禁用项目名编辑。

此时你可以：

1. 点击「选择文件夹」。
2. 选择新的本地素材路径。
3. 点击「更改项目路径」。

这不会重命名达芬奇项目，只会更新 QuickClip 记录的本地路径。

### 6.5 与其他功能的关系

项目初始化是很多功能的前置条件：

- 「导出与备份」会用项目路径推导默认导出目录。
- 「剪贴导入」会把图片保存到项目路径下。
- 「素材打包」会根据项目路径还原素材层级。
- 「音效库」收集音效时会复制到项目路径下。
- 「文本剪辑」跨项目使用时会把源素材导入当前项目路径。

如果你发现某个功能的路径不对，优先回到「项目初始化」检查本地素材路径。

### 6.6 项目初始化里的文件结构与映射规则

项目初始化页面内嵌了文件结构配置，也可以从项目初始化进入子页面：

- 本地文件结构。
- 达芬奇媒体池结构。
- 导入映射规则。

#### 6.6.1 本地文件结构

本地文件结构用于定义硬盘上的项目目录层级。例如：

```text
项目根目录
├── 视频
├── 音频
├── 图片
├── 字幕
├── 导出
└── 音效
```

使用方式：

1. 进入「项目初始化」。
2. 打开「本地文件结构」。
3. 新增、重命名、删除或排序文件夹。
4. 保存配置。

建议把高频使用目录固定下来，例如「视频」「音频」「图片」「导出」「音效」。这样剪贴导入、音效收集和导出会更稳定。

#### 6.6.2 达芬奇媒体池结构

达芬奇媒体池结构用于定义 Bin 层级。例如：

```text
Master
├── 视频
├── 音频
├── 图片
├── 字幕
└── 音效
```

使用方式：

1. 进入「达芬奇媒体池结构」。
2. 按项目习惯创建媒体池目录。
3. 保存配置。
4. 需要同步到达芬奇时，确保达芬奇已连接。

#### 6.6.3 导入映射规则

导入映射规则用于说明「本地哪个目录」对应「达芬奇哪个媒体池目录」。

示例：

| 本地目录 | 达芬奇媒体池目录 | 适合素材 |
|---|---|---|
| `视频` | `视频` | 拍摄素材、成片素材 |
| `音频` | `音频` | 录音、旁白、音乐 |
| `图片` | `图片` | 截图、贴图、参考图 |
| `音效` | `音效` | 音效库收集或剪贴导入 |

配套使用场景：

- 剪贴导入会读取本地保存位置和媒体池目标目录。
- 音效库会读取本地保存子目录和达芬奇归档目录。
- 文本剪辑跨项目导入会读取本地导入路径和媒体池路径。

## 7. 文件层级管理

### 7.1 功能用途

「文件层级管理」用于查看达芬奇媒体池中的文件夹层级，并对深层嵌套文件夹做整理。

典型问题：

- 素材导入后层级太深。
- 多级文件夹导致查找素材困难。
- 图片素材散落在多个深层目录。
- 想把深层素材移动到保留层级内。

### 7.2 查看媒体池层级

操作步骤：

1. 打开 DaVinci Resolve 并进入目标项目。
2. 进入 QuickClip 的「文件层级管理」。
3. 页面会自动读取媒体池层级。
4. 如未加载，点击刷新。

页面中每个文件夹会显示素材类型统计，例如视频、音频、图片等。

### 7.3 展平文件夹

展平的意思是：把超过指定层级的深层素材移动到更浅的目标文件夹中。

操作步骤：

1. 勾选要处理的文件夹。
2. 设置「保留层级」。
3. 查看右侧或下方的实时预览。
4. 确认将被移动的素材数量和目标位置。
5. 点击执行展平。

示例：

如果选择 `素材/客户给的素材`，保留 2 层，那么更深的 `素材/客户给的素材/图片/截图/第 1 批` 会被整理到保留层级内。

使用建议：

- 第一次整理前先只勾选一个小文件夹。
- 先看预览，不要直接全选执行。
- 对已经人工整理好的目录谨慎使用。

### 7.4 删除图片素材

文件层级管理也支持删除所选文件夹范围内的图片类素材。

适合场景：

- 批量清理剪贴导入产生的临时图片。
- 删除不再使用的参考图。
- 清理深层目录里的静帧。

操作步骤：

1. 勾选目标文件夹。
2. 查看页面统计的图片数量。
3. 点击删除图片。
4. 在确认弹窗中检查将删除的范围。
5. 确认后执行。

注意：该操作会影响达芬奇媒体池中的图片素材，请在确认范围后再执行。

### 7.5 配套使用

推荐搭配：

- 与「剪贴导入」配合：定期整理复制图片产生的媒体池目录。
- 与「素材打包」配合：打包前先整理媒体池结构，交付目录更清晰。
- 与「项目初始化」配合：提前设计好本地目录和媒体池目录，减少后续整理成本。

## 8. 素材打包

### 8.1 功能用途

「素材打包」用于扫描当前达芬奇时间线引用到的素材，并把选中的素材复制到指定目录。

适合场景：

- 项目交接。
- 素材归档。
- 只交付当前成片用到的素材。
- 按轨道或片段选择要打包的素材。

### 8.2 扫描时间线素材

操作步骤：

1. 在达芬奇中打开需要打包的时间线。
2. 进入「素材打包」。
3. 页面会尝试扫描当前时间线。
4. 如果没有自动扫描，点击刷新或重新扫描。

扫描结果会按视频轨、音频轨和片段层级展示。对于复合片段、关联素材或 Fusion 引用，页面会尽量展示其依赖关系。

### 8.3 选择打包范围

你可以按以下粒度选择：

- 勾选整个视频轨。
- 勾选整个音频轨。
- 勾选单个片段。
- 勾选片段内的关联素材。

建议：

- 交付完整项目时，选择所有视频轨和音频轨。
- 只交付画面素材时，仅选择视频轨。
- 音频外包时，仅选择音频轨。
- 对复杂合成片段，展开后检查内部引用。

### 8.4 设置打包目录

操作步骤：

1. 点击选择目标文件夹。
2. 选择交付或备份目录。
3. 如需保留层级，配置文件夹层级策略。
4. 查看层级预览。
5. 点击打包。

### 8.5 层级预览

素材打包支持预览打包后的目录结构。它会根据：

- 所选素材路径。
- 项目本地根目录。
- 文件夹层级配置。
- 当前媒体池路径。

计算打包后文件夹结构。

如果预览里出现冲突或重复文件，建议先调整目标目录或层级策略。

### 8.6 配套使用

推荐搭配：

- 打包前使用「时间线检查」确认成片没有明显技术问题。
- 打包前使用「文件层级管理」整理媒体池结构。
- 打包后使用「导出与备份」输出同版本视频和时间线备份。

## 9. 导出与备份

### 9.1 功能用途

「导出与备份」用于快速生成规范文件名，并调用达芬奇渲染或只备份当前时间线。

它解决的问题：

- 每次导出手动改文件名容易出错。
- 多版本命名不统一。
- 忘记备份时间线。
- 不同时间线需要不同版本号。

### 9.2 选择导出目录

页面会根据项目路径推导默认导出目录。你也可以手动选择。

如果选择的目录位于项目根目录下，软件会尽量保存相对路径，方便项目迁移。

### 9.3 命名模板

可用标签：

| 标签 | 输出含义 |
|---|---|
| 项目名 | 当前达芬奇项目名 |
| 时间线 | 当前时间线名称 |
| 日期时间 | 当前日期时间，可配置年月日时分秒 |
| 版本号 | 例如 `V01`、`V02` |

默认模板通常类似：

```text
项目名_时间线_日期时间_V01
```

使用方式：

1. 点击标签添加到模板。
2. 拖动标签调整顺序。
3. 编辑版本号。
4. 设置分隔符，例如 `_`。
5. 查看实时预览。

导出成功后，版本号会自动递增，并按当前时间线保存。

### 9.4 渲染预设

QuickClip 会从达芬奇读取渲染预设，并过滤保留常用预设，例如：

- H.264 Master。
- H.265 Master。
- HyperDeck。
- ProRes 422 HQ。
- 用户自定义预设。

如果预设列表为空，请先检查：

1. 达芬奇是否已连接。
2. 当前项目是否正常打开。
3. 达芬奇中是否存在可用渲染预设。

### 9.5 子文件夹

可以选择将导出文件放入子文件夹：

- 按时间线名称创建。
- 使用自定义子文件夹名。

适合多条时间线同时交付的项目。

### 9.6 执行导出

操作步骤：

1. 选择导出目录。
2. 选择渲染预设。
3. 组合文件名模板。
4. 检查预览文件名。
5. 点击导出。

QuickClip 会把渲染任务提交给达芬奇。渲染进度仍在 DaVinci Resolve 的交付页面中查看。

### 9.7 仅备份

如果只想保存当前时间线状态，不进行渲染，可以点击仅备份。

适合场景：

- 重要修改前保存一个版本。
- 交付前备份当前时间线。
- 客户反馈修改前保留原始状态。

## 10. 音频转录

### 10.1 功能用途

「音频转录」用于把视频或音频转换成带时间戳的文本，并生成可用于文本剪辑和字幕处理的转录项目。

支持来源：

| 来源 | 说明 | 适合场景 |
|---|---|---|
| 达芬奇时间线 | 从当前时间线导出音频后转录 | 已经在达芬奇中粗剪或铺好素材 |
| 本地文件 | 直接选择或拖拽本地音视频文件 | 单独转录某个素材 |

### 10.2 使用前准备

请先确认：

1. 偏好设置中 faster-whisper 模型已安装。
2. 如果要说话人分离，相关模型也已安装。
3. 如果来源是达芬奇时间线，达芬奇必须已连接并打开时间线。
4. 如果来源是本地文件，文件路径需要能被本机访问。

### 10.3 从达芬奇时间线转录

操作步骤：

1. 在达芬奇中打开目标时间线。
2. 进入「音频转录」。
3. 来源选择「达芬奇时间线」。
4. 选择语言，或使用自动检测。
5. 按需开启说话人分离。
6. 按需设置每行最大字数。
7. 点击开始生成。

软件会先从达芬奇导出音频，再进行语音识别。

### 10.4 从本地文件转录

操作步骤：

1. 进入「音频转录」。
2. 来源选择「本地文件」。
3. 点击选择文件，或把音视频文件拖入页面。
4. 选择语言和转录参数。
5. 点击开始生成。

本地文件转录不会要求该文件已经导入达芬奇，但后续如果要生成达芬奇时间线，仍需要能找到或导入对应素材。

### 10.5 语言选择

常用语言包括：

- 自动检测。
- 中文。
- 英文。
- 日文。
- 韩文。
- 德文。
- 法文。
- 西班牙文。
- 葡萄牙文。
- 意大利文。

如果素材主要是中文，建议直接选择中文，减少自动检测误差。

### 10.6 专有名词词库

专有名词词库用于提升特定词的识别准确率，例如：

- 人名。
- 品牌名。
- 产品名。
- 栏目名。
- 行业术语。
- 英文缩写。

使用方式：

1. 在音频转录页面创建词库。
2. 每行输入一个专有名词。
3. 选择当前使用的词库。
4. 开始转录。

建议把不同项目、不同客户、不同主题分成不同词库。

### 10.7 说话人分离

开启说话人分离后，转录结果会尝试给不同说话人分组。

适合：

- 访谈。
- 圆桌讨论。
- 多人会议。
- 主持人与嘉宾对话。

注意：

- 说话人分离依赖额外模型。
- 背景噪声大、多人抢话时准确率会下降。
- 转录完成后仍可以在「文本剪辑」中手动修改说话人。

### 10.8 AI 优化

音频转录可配合 AI 优化做错别字修正、断句和专有名词优化。使用前需要在页面或偏好配置中填写 API Key、Base URL 和模型名。

适合场景：

- 需要更自然的字幕断句。
- 采访中有很多专业词。
- 初始识别文本可读性不足。

### 10.9 转录完成后的结果

转录完成后会产生：

- 转录文本。
- 字幕段落。
- 词级时间戳。
- 说话人信息。
- 转录项目记录。

这些结果会流向：

- 「文本剪辑」用于选择内容并生成时间线。
- 「字幕处理」用于编辑和插入字幕。
- 「转录项目管理」用于后续重新加载。

## 11. 文本剪辑

### 11.1 功能用途

「文本剪辑」是 QuickClip 的核心功能。它让你像整理文稿一样剪辑视频：选中想保留的句子或词语，然后生成达芬奇时间线。

适合：

- 采访粗剪。
- 口播精简。
- 课程剪辑。
- 从长素材中挑选高光片段。
- 多说话人内容筛选。

### 11.2 加载转录项目

进入页面后，顶部会显示可用转录项目标签。

可执行操作：

- 点击标签切换转录项目。
- 点击刷新获取最新项目。
- 点击管理调整绑定关系。
- 关闭或删除不需要的转录项目。

如果当前没有转录数据，请先进入「音频转录」生成转录项目。

### 11.3 块状视图与表格视图

文本剪辑提供两种视图：

| 视图 | 特点 | 适合场景 |
|---|---|---|
| 块状视图 | 按说话人和段落展示，阅读感更强 | 访谈、口播、需要看上下文 |
| 表格视图 | 按行展示时间码、说话人和文本 | 快速批量选择、检查时间点 |

建议：

- 初筛用块状视图。
- 精确检查用表格视图。
- 大量连续选择时用表格视图更快。

### 11.4 说话人管理

支持：

- 自动识别说话人。
- 重命名说话人。
- 添加自定义说话人。
- 删除自定义说话人。
- 修改单段或一组段落的说话人。
- 按说话人筛选显示内容。

使用建议：

- 先给主要人物重命名，例如「主持人」「嘉宾 A」。
- 筛选单个说话人后再选择内容，可以减少误选。
- 多人混说片段需要人工复核。

### 11.5 整段选择

操作方式：

- 点击段落或表格行，切换选中状态。
- 在表格视图中按住 Shift 点击，可选择连续范围。
- 可以一键选择当前可见内容。
- 可以清空全部选择。

选中后页面会统计：

- 已选片段数量。
- 已选总时长。

### 11.6 词级选择

如果转录结果包含词级时间戳，可以只选择一句中的部分词。

操作方式：

- 点击单个词切换选中。
- 拖拽经过多个词形成连续选择。
- Shift 点击可从锚点扩展选择。
- 再次点击已选词可取消。

词级选择适合：

- 删除口头禅。
- 只取一句话中间的关键信息。
- 避免整句过长。
- 精确保留问题或回答的一部分。

### 11.7 编辑文本

支持：

- 修改段落文本。
- 修改单个词文本。
- 拆分段落。
- 智能分句。
- 撤销部分编辑操作。

注意：编辑文本主要影响文稿和字幕显示。真正剪辑使用的是时间戳，因此不要随意改动会导致时间含义不清的文本结构。

### 11.8 生成新时间线

适合从长素材中生成一版精选时间线。

操作步骤：

1. 选择需要保留的句子或词语。
2. 底部选择「创建新时间线」。
3. 点击应用。
4. 等待达芬奇创建新时间线。

结果：

- 选中内容会按原时间顺序组成新时间线。
- 连续或间隔较短的选区会尽量合并，减少碎片。

### 11.9 追加到末尾

适合把新选中的内容追加到当前剪辑后面。

操作步骤：

1. 在达芬奇中打开目标时间线。
2. 在文本剪辑中选择内容。
3. 底部选择「追加到末尾」。
4. 点击应用。

适合增量工作，例如每天从新素材里选几段追加到同一条汇总时间线。

### 11.10 跨项目文本剪辑

如果当前达芬奇项目与转录项目来源项目不同，页面会显示导入路径设置。

需要设置：

- 本地导入路径。
- 达芬奇媒体池路径。

作用：

- 将源素材复制或导入到当前项目目录。
- 确保新时间线中的片段能在当前达芬奇项目中找到媒体。

使用建议：

- 跨项目复用采访素材时，先确认本地导入路径。
- 媒体池路径建议与项目映射规则一致。

## 12. 字幕处理

### 12.1 功能用途

「字幕处理」用于编辑字幕文本、调整字幕结构、从达芬奇拉取已有字幕、插入字幕到达芬奇，以及在时间线变动后同步字幕。

适合：

- 转录后制作 SRT。
- 修改错字。
- 合并或拆分字幕。
- 搜索替换统一术语。
- 把字幕插入达芬奇。
- 对变速时间线做字幕同步。

### 12.2 加载字幕来源

字幕数据可以来自：

- 音频转录自动生成的字幕段落。
- 已保存的转录项目。
- 本地导入的 SRT 文件。
- 从达芬奇当前时间线拉取的字幕。

### 12.3 从达芬奇拉取字幕

操作步骤：

1. 在达芬奇中打开含字幕的时间线。
2. 进入「字幕处理」。
3. 点击「从达芬奇拉取」。

成功后，页面会显示当前时间线中的字幕段落。

### 12.4 导入本地字幕

操作步骤：

1. 点击「导入本地字幕」。
2. 选择 `.srt` 文件。
3. 页面会解析字幕编号、时间码和文本。

导入本地字幕后，当前转录项目选择会被清空，避免误以为该字幕仍绑定某个转录项目。

### 12.5 编辑字幕

支持操作：

- 直接修改字幕文本。
- 修改开始时间和结束时间。
- 删除某条字幕。
- 合并当前字幕到上一条。
- 点击定位到达芬奇时间线对应位置。
- 保存修改到当前转录项目。

### 12.6 智能换行

在字幕文本输入框中按 Enter，会把当前字幕拆成两条。

拆分逻辑：

- 如果有词级时间戳，会尽量按词时间戳计算拆分时间。
- 如果没有词级时间戳，会按文字长度比例估算时间。

如果在文本开头按 Backspace，会尝试与上一条字幕合并。

### 12.7 查找替换

操作方式：

1. 点击「查找替换」，或按 `Cmd+F` / `Ctrl+F`。
2. 输入查找词。
3. 输入替换词。
4. 选择是否区分大小写。
5. 选择是否整词匹配。
6. 可逐条替换，也可全部替换。

替换后可以撤回到替换前快照。

适合：

- 统一人名。
- 统一品牌名。
- 修正高频错别字。
- 替换口头表达。

### 12.8 下载 SRT

点击「下载 SRT」会把当前字幕列表导出为 SRT 文件。文件名会尽量使用当前转录项目名。

适合：

- 上传平台字幕。
- 给客户审阅。
- 交给其他软件继续处理。

### 12.9 插入字幕

操作步骤：

1. 检查字幕内容和时间。
2. 点击「插入字幕」。
3. QuickClip 会把当前字幕段落发送到达芬奇。

如果自动插入失败，后端可能会保存 SRT 文件并返回手动导入提示。

### 12.10 同步时间线

当转录来源带有片段映射时，页面会显示「同步时间线」。

作用：

- 保留已有字幕。
- 根据剪辑后的片段映射补齐缺失字幕。
- 用最小间隔参数控制新增字幕判断。

使用方式：

1. 设置间隔阈值。
2. 点击「同步时间线」。
3. 检查生成的字幕预览。
4. 确认后点击「插入字幕」。

### 12.11 自动同步字幕

自动同步字幕用于时间线继续变动时持续跟踪字幕位置。

开启流程：

1. 先确保达芬奇时间线上已有字幕轨。
2. 选择要绑定的音频轨，例如 A1。
3. 打开「自动同步字幕」开关。
4. 软件会获取字幕和轨道信息，并开始轮询变化。

适合：

- 时间线有变速。
- 粗剪后继续调整片段。
- 需要字幕跟随音频切分变化。

注意：

- 自动同步运行时，不建议切换转录项目。
- 关闭页面时会尝试停止追踪。
- 如果轨道选择错误，字幕对齐可能不符合预期。

## 13. 同步审阅

### 13.1 功能用途

「同步审阅」用于从阅流分享链接中拉取评论，并把评论与达芬奇时间线时间点对应起来。

适合：

- 客户反馈整理。
- 团队审片修改。
- 按时间戳逐条处理意见。
- 把评论写入达芬奇标记。

### 13.2 创建审阅项目

操作步骤：

1. 进入「同步审阅」。
2. 粘贴阅流链接。
3. 点击拉取，或使用粘贴读取功能。
4. 等待解析分享、文件列表和评论。

拉取成功后会创建一个审阅项目，并显示文件、评论数量和评论内容。

### 13.3 审阅项目管理

支持：

- 多审阅链接并存。
- 切换审阅项目。
- 关闭审阅项目。
- 管理项目名称。
- 删除不需要的审阅链接。
- 设置绑定范围。

绑定方式与转录项目类似：

- 全局。
- 当前项目。
- 指定达芬奇项目。

### 13.4 查看和筛选评论

评论信息包括：

- 评论者。
- 评论内容。
- 时间戳。
- 创建时间。
- 回复数量。

可以通过关键词搜索：

- 评论内容。
- 评论者名称。
- 时间戳。

### 13.5 跳转时间线

点击评论时间戳可以让达芬奇跳转到对应时间位置。

前提：

- DaVinci Resolve 已连接。
- 当前打开的时间线与审阅文件对应。

如果跳转位置不准确，请检查审阅视频与当前时间线是否同版本。

### 13.6 标记完成

处理完一条评论后，可以标记为完成。这样可以统计处理进度，避免遗漏。

建议工作方式：

1. 按时间顺序处理评论。
2. 每完成一条就标记完成。
3. 对无法处理的问题保留未完成状态。
4. 最后通过未完成列表复查。

### 13.7 添加达芬奇标记

可以把某个文件下的评论批量写入达芬奇时间线标记。

作用：

- 在达芬奇内部直接看到审阅意见。
- 和剪辑师原生工作流兼容。
- 即使关闭 QuickClip，也能在时间线上保留修改提示。

也可以移除已经写入的审阅标记。

## 14. 时间线检查

### 14.1 功能用途

「时间线检查」用于扫描当前达芬奇时间线中的技术问题。

支持检查：

| 检查项 | 说明 |
|---|---|
| 夹帧 | 识别过短素材片段 |
| 黑帧间隙 | 扫描轨道间的空白无信号区域 |
| 黑边风险 | 识别缩放或比例不匹配导致的黑边 |

### 14.2 检查夹帧

夹帧阈值单位是帧。默认可以设置为小于等于 3 帧。

示例：

- 阈值为 3，表示长度小于等于 3 帧的片段会被视为风险。
- 如果项目中有故意保留的极短闪白或特效，可以关闭夹帧检查。

### 14.3 检查黑帧间隙

黑帧间隙用于发现时间线上没有被有效画面覆盖的区域。

适合交付前检查：

- 两段素材之间是否有空隙。
- 上层轨道是否没有覆盖下层。
- 是否出现误删片段后的空洞。

### 14.4 检查黑边风险

黑边风险用于检查缩放、比例、旋转、裁切导致画面没有铺满时间线画幅的问题。

可以设置安全区数值。安全区越大，检查越严格。

### 14.5 定位问题

检查完成后，页面会列出问题。点击定位后，达芬奇会跳转到对应时间线位置。

建议：

1. 先全部检查。
2. 从严重问题开始定位。
3. 修复后重新检查。

### 14.6 添加和删除问题标签

可以把检查结果写入达芬奇时间线标记。

支持按类型选择：

- 黑边片段。
- 夹帧片段。
- 黑帧片段。

也可以删除所选类型的问题标签。页面支持 Delete 或 Backspace 快捷键删除所选标签。

### 14.7 配套使用

推荐在以下节点使用：

- 导出前。
- 审阅修改完成后。
- 素材打包前。
- 大量文本剪辑生成时间线后。

## 15. 剪贴导入

### 15.1 功能用途

「剪贴导入」用于监听系统剪贴板中的图片，并自动保存到项目目录，再导入达芬奇媒体池。

适合：

- 从浏览器、聊天软件、设计稿中复制参考图。
- 快速把截图放入达芬奇。
- 不想手动保存文件再导入媒体池。

### 15.2 使用前准备

请先确认：

1. 已完成项目初始化。
2. 已选择本地保存位置。
3. 已选择达芬奇媒体池目录。
4. 达芬奇已连接。

### 15.3 设置保存位置

「保存位置（本地）」决定复制来的图片保存到项目目录下哪个文件夹。

建议选择：

- `图片`。
- `参考图`。
- `截图`。

### 15.4 设置媒体池目录

「媒体池目录（达芬奇）」决定图片导入到达芬奇的哪个 Bin。

建议与本地保存位置一致，例如本地保存到 `图片`，媒体池也选择 `图片`。

### 15.5 开始监听

操作步骤：

1. 点击「开始监听」。
2. 从其他软件复制图片。
3. 回到 QuickClip 查看导入历史。
4. 在达芬奇媒体池中检查是否已导入。

状态说明：

| 状态 | 含义 |
|---|---|
| 监听中 | 剪贴板服务正在运行 |
| 启动中 | 已开启但服务仍在准备 |
| 已暂停 | 当前不会监听剪贴板 |
| 监听启动失败 | 环境或权限异常 |
| 当前环境不支持剪贴板监听 | 当前运行环境无法使用该功能 |

### 15.6 导入历史

导入历史会显示：

- 文件名。
- 文件大小。
- 导入状态。
- 跳过或失败信息。

可以清空历史，但清空历史不会删除已经保存的图片文件。

### 15.7 配套使用

推荐搭配：

- 与「文件层级管理」配合，定期清理图片素材。
- 与「项目初始化」配合，统一设置图片保存目录。
- 与「素材打包」配合，确保需要交付的参考图被正确引用。

## 16. 偏好设置

### 16.1 功能用途

「偏好设置」是主工作区左侧导航的最后一项，用于集中管理系统环境、模型、主题、更新、技能和第三方配置。

它不是某一个剪辑动作，而是所有功能的运行基础。尤其是音频转录、字幕处理和达芬奇连接异常时，通常都要回到这里检查环境状态。

### 16.2 运行环境检查

偏好设置会检查：

- 后端服务。
- Python。
- FFmpeg。
- faster-whisper。
- 说话人分离模型。

如果有异常，环境面板会自动展开。

各项状态含义：

| 项目 | 正常时 | 异常时影响 |
|---|---|---|
| 后端服务 | QuickClip 本地 API 可访问 | 所有需要后端的功能都可能失败 |
| Python | 后端运行环境可用 | 转录、音频处理、达芬奇接口可能不可用 |
| FFmpeg | 可导出和处理音频 | 时间线转录、音频预览、波形生成可能失败 |
| faster-whisper | 本地转录模型可用 | 音频转录不可用或只能模拟 |
| 说话人分离模型 | 可识别不同说话人 | 转录能执行，但说话人分离不可用 |

### 16.3 模型安装和删除

如果模型缺失，可以点击安装。安装过程中会显示：

- 当前阶段。
- 下载进度。
- 下载速度。
- 已用时间。
- 错误信息。

安装期间可以切换到其他页面，但不建议关闭软件。模型安装完成后，重新进入「音频转录」即可使用。

如果模型损坏或需要释放空间，可以删除模型后重新安装。

### 16.4 更新检查

Tauri 桌面环境下会尝试读取当前应用版本，并检查是否有新版本。

可能结果：

| 结果 | 含义 |
|---|---|
| 已是最新 | 当前版本无需更新 |
| 有新版本 | 可以根据提示获取新版安装包 |
| 检查失败 | 通常是网络或更新源不可达，不影响本地剪辑功能 |

### 16.5 主题

支持：

- 跟随系统。
- 浅色。
- 深色。

主题设置会保存到本地。它只影响界面显示，不影响项目数据。

### 16.6 技能安装

偏好设置会列出随软件打包的技能，支持安装和卸载。技能用于扩展 QuickClip 与外部工具或工作流的配合能力。

普通用户如果只使用转录、剪辑、字幕、审阅、导出等内置功能，可以保持默认状态。

### 16.7 第三方配置

偏好设置中还可能出现第三方平台配置，例如飞书相关 App ID、App Secret、用户 ID 等。

填写这类配置前，请确认你确实需要对应集成。普通本地转录、文本剪辑、字幕和导出不依赖这些配置。

### 16.8 配套使用

当某个功能异常时，可以按以下方式回到偏好设置排查：

| 异常功能 | 优先检查 |
|---|---|
| 音频转录失败 | FFmpeg、faster-whisper、Python |
| 说话人分离无效 | 说话人分离模型 |
| 字幕自动同步异常 | 后端服务、DaVinci 连接状态 |
| 音效波形无法生成 | FFmpeg |
| 软件版本问题 | 更新检查 |

## 17. 音效库

### 17.1 功能用途

音效库是独立工作区，用于管理本地音效素材。它支持索引、搜索、试听、波形预览、收藏、标签、智能文件夹、收集到项目、拖拽到达芬奇和直接插入时间线。

### 17.2 进入音效库

在顶部工作区切换到「音效库」。默认会进入 `/sfx/library`。

侧边栏主要入口：

- 全部。
- 收藏。
- 最近。
- 项目已用。
- 标签。
- 智能文件夹。
- 设置。

### 17.3 配置音效库路径

首次使用：

1. 进入音效库「设置」。
2. 选择音效库根目录。
3. 设置项目内保存子目录，例如 `音效`。
4. 设置达芬奇归档目录，例如 `音效`。
5. 设置保留文件夹深度。
6. 保存配置。

### 17.4 建立本地索引

选择音效库路径后，QuickClip 会扫描音频文件并建立本地索引。

索引阶段可能包括：

- 首次建立索引。
- 扫描音效文件。
- 写入本地索引。
- 读取已有索引。
- 重建索引。

音效数量较大时，首次扫描需要等待。后续会使用缓存加速。

### 17.5 浏览和搜索

支持：

- 按文件夹浏览。
- 搜索文件名。
- 搜索路径。
- 搜索标签。
- 只看收藏。
- 只看未分类。
- 按标签进入。
- 按智能文件夹进入。

常见筛选：

| 入口 | 说明 |
|---|---|
| 全部 | 查看当前库全部音效 |
| 收藏 | 只看已收藏音效 |
| 最近 | 查看最近使用过的音效 |
| 项目已用 | 查看已被当前项目使用过的音效 |
| 未分类 | 查看没有标签的音效 |

### 17.6 波形预览和试听

音效卡片和详情区域会显示波形。

支持：

- 播放和暂停。
- 点击波形跳转播放位置。
- 设置入点和出点。
- 清除入点和出点。
- 预生成波形缓存。

入点和出点适合只取音效中的一小段，例如只取一个转场冲击点。

### 17.7 收藏和标签

支持单个音效：

- 添加收藏。
- 取消收藏。
- 添加标签。
- 删除标签。

支持批量：

- 给多个选中音效添加标签。
- 从多个选中音效移除标签。
- 收集多个选中音效到项目。

建议标签体系：

- 类型：`whoosh`、`hit`、`rise`、`ambience`。
- 情绪：`紧张`、`轻松`、`科技`。
- 用途：`转场`、`按钮`、`字幕弹出`。

### 17.8 智能文件夹

智能文件夹会按规则自动筛选音效。

可用规则包括：

- 标签包含某个词。
- 只看收藏。
- 只看未分类。
- 最近使用。
- 已在项目中使用。

适合建立：

- 常用转场。
- 待整理音效。
- 本周项目常用。
- 客户专属音效。

### 17.9 收集到项目

「收集」会把音效从音效库复制到当前项目目录。它适合在交付或归档前，把外部音效库中的素材纳入项目文件夹。

操作步骤：

1. 选中一个或多个音效。
2. 点击收集。
3. QuickClip 会根据设置复制到项目内保存子目录。
4. 后续素材打包时更容易包含这些音效。

### 17.10 拖拽到达芬奇

音效库支持把音效拖到达芬奇时间线。

流程：

1. QuickClip 为音效准备本地副本。
2. 启动系统拖拽。
3. 你把文件拖入达芬奇时间线。
4. 达芬奇导入或放置该音频。

如果拖拽启动失败，页面会提示手动从项目文件夹拖入达芬奇。

### 17.11 直接插入时间线

也可以通过「插入到时间线」直接把音效放入当前时间线。

适合：

- 已经确定音效要放到播放头位置。
- 希望使用入点、出点裁切后的音效。
- 不想手动拖拽。

使用前请确认达芬奇已连接，且当前时间线可写入。

### 17.12 缓存管理

音效库有多类缓存：

- 浏览索引缓存。
- 波形缓存。
- 预览音频缓存。

缓存能显著提高大音效库的浏览速度。如果磁盘空间紧张，可以在设置中清理缓存。

## 18. 功能之间的配套关系

### 18.1 项目路径是所有素材功能的基础

关系链：

```text
项目初始化
→ 本地素材路径
→ 剪贴导入 / 音效收集 / 导出目录 / 素材打包
```

如果路径配置不正确，后续功能会出现连锁问题。遇到路径异常，先检查项目初始化。

### 18.2 转录项目贯穿 AI 工作流

关系链：

```text
音频转录
→ 转录项目
→ 文本剪辑
→ 字幕处理
→ 达芬奇时间线
```

一个转录项目可以同时服务粗剪和字幕。不要在不同达芬奇项目之间随意复用转录项目，除非你明确使用全局绑定或跨项目导入。

### 18.3 文本剪辑和字幕处理的区别

| 功能 | 核心对象 | 输出 |
|---|---|---|
| 文本剪辑 | 被选中的话语片段 | 新时间线或追加片段 |
| 字幕处理 | 字幕条目 | SRT 文件或达芬奇字幕轨 |

简单说：

- 想剪画面，用「文本剪辑」。
- 想改字幕，用「字幕处理」。

### 18.4 审阅同步和时间线检查的顺序

推荐顺序：

1. 同步审阅，处理客户或团队意见。
2. 时间线检查，发现技术问题。
3. 导出与备份，输出新版本。

原因：

- 审阅修改会改变时间线。
- 修改后再做技术检查更可靠。
- 检查通过后再导出能减少返工。

### 18.5 音效库和素材打包的关系

如果音效直接来自外部音效库，素材打包时可能需要确保音效已被复制到项目目录。

推荐：

1. 在音效库中使用「收集」把音效复制到项目。
2. 再插入或拖入达芬奇。
3. 最后用「素材打包」打包当前时间线。

这样交付时更不容易丢失外部音效文件。

### 18.6 剪贴导入和文件层级管理的关系

剪贴导入很方便，但长期使用会产生大量图片素材。建议定期：

1. 进入「文件层级管理」。
2. 查看图片素材集中在哪些目录。
3. 展平过深目录。
4. 删除不再需要的图片素材。

## 19. 常见问题

### 19.1 QuickClip 连接不上达芬奇

检查顺序：

1. DaVinci Resolve 是否启动。
2. 是否打开了项目。
3. 是否打开了时间线。
4. 达芬奇是否启用了外部脚本控制。
5. QuickClip 底部状态栏是否可点击重连。
6. 后端服务是否正常运行。

### 19.2 转录按钮不可用或转录失败

检查顺序：

1. 偏好设置中的 faster-whisper 是否已安装。
2. FFmpeg 是否可用。
3. 本地文件路径是否存在。
4. 达芬奇时间线是否有可导出的音频。
5. 是否选择了正确来源。
6. 磁盘空间是否足够。

### 19.3 说话人分离没有效果

可能原因：

- 说话人分离模型未安装。
- 素材只有一个人说话。
- 背景噪声过大。
- 多人同时说话。
- 音轨混音导致声纹不清晰。

建议先确认模型状态，再用音质较好的片段测试。

### 19.4 文本剪辑生成时间线失败

检查顺序：

1. 是否已经选择了片段。
2. 达芬奇是否连接。
3. 当前项目是否打开。
4. 源文件是否仍在原路径。
5. 跨项目使用时是否设置了导入路径和媒体池路径。
6. 当前时间线是否可写入。

### 19.5 字幕插入失败

检查顺序：

1. 字幕列表是否为空。
2. 达芬奇是否连接。
3. 当前时间线是否打开。
4. 字幕时间是否有效。
5. 是否存在结束时间早于开始时间的字幕。

如果自动插入失败，查看返回的手动导入说明或 SRT 文件路径。

### 19.6 自动同步字幕不准确

检查顺序：

1. 是否选择了正确的音频轨。
2. 时间线上是否已有字幕。
3. 字幕是否与当前版本时间线匹配。
4. 时间线是否刚刚做过大范围移动。
5. 是否需要先关闭再重新开启自动同步。

### 19.7 剪贴导入没有反应

检查顺序：

1. 是否点击了开始监听。
2. 状态是否为监听中。
3. 当前环境是否支持剪贴板监听。
4. 是否已经选择本地保存位置。
5. 是否已经选择达芬奇媒体池目录。
6. 复制的内容是否为图片或支持的文件。

### 19.8 音效库扫描很慢

可能原因：

- 首次扫描音效数量很多。
- 音效库位于外接硬盘或网络盘。
- 波形缓存尚未生成。
- 文件夹层级过深。

建议：

- 首次扫描完成后再使用。
- 常用音效库放在本地磁盘。
- 对大型音效库建立标签和智能文件夹。
- 定期清理无效路径。

### 19.9 导出预设为空

检查顺序：

1. 达芬奇是否连接。
2. 当前项目是否打开。
3. 达芬奇中是否有渲染预设。
4. 当前预设是否被过滤规则隐藏。

可以先在达芬奇交付页面确认预设存在。

## 20. 最佳实践

### 20.1 新项目先做结构，再导入素材

推荐顺序：

1. 项目初始化。
2. 配置本地文件结构。
3. 配置达芬奇媒体池结构。
4. 配置映射规则。
5. 导入素材。

这样后面的剪贴导入、音效收集和素材打包都会更顺。

### 20.2 每个项目维护独立转录项目

除非明确需要复用，否则建议让转录项目绑定到原始达芬奇项目。这样可以减少误加载其他项目文稿的风险。

### 20.3 导出前固定检查流程

建议每次交付前固定执行：

1. 同步审阅，确认反馈处理完。
2. 时间线检查，修复夹帧、黑帧和黑边。
3. 仅备份当前时间线。
4. 正式导出。
5. 如需交接，再素材打包。

### 20.4 音效先收集，再交付

如果音效来自公共音效库，交付前务必收集到项目目录，避免别人打开项目时丢音效。

### 20.5 大操作前先备份

以下操作前建议使用「导出与备份」中的仅备份：

- 大量文本剪辑生成新时间线。
- 批量展平媒体池文件夹。
- 批量删除图片素材。
- 大范围处理审阅修改。
- 自动同步字幕前的复杂时间线。
